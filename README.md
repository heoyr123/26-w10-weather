# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

> Open-Meteo 글로벌 기상/대기질 공개 API와 React 19, Vite를 활용하여 구축한 실시간 반응형 기상 대시보드 웹 애플리케이션입니다.

---

## 🌤️ 소개

전 세계 주요 도시의 실시간 기상 상태, 미세먼지/초미세먼지 농도, 향후 24시간 기온 추이, 7일간 주간 일기예보를 직관적인 카드형 UI로 제공하는 종합 기상 대시보드입니다.

- **8대 주요 도시 원클릭 조회**: 서울(강서), 서울(시청), 인천, 부산, 대구, 대전, 광주, 제주 빠른 선택
- **실시간 날씨 & 미세먼지 카드**: WMO 기상 코드 연동 한국어 상태 표시 및 환경부 CAI 기준 4단계(좋음/보통/나쁨/매우나쁨) 미세먼지·초미세먼지 컬러 뱃지
- **24시간 기온 변화 SVG 차트**: 외부 라이브러리 없이 경량 SVG로 구현된 24시간 기온 꺾은선 추이 및 최고/최저 기온 하이라이트
- **7일간 주간 예보**: 향후 일주일간의 날씨 아이콘, 강수 확률(%), 주간 기온 범위 그라데이션 바(Bar)
- **스마트 도시 검색**: 400ms 디바운스(Debounce) 기반 전 세계 도시 지오코딩 검색 및 드롭다운
- **나만의 커스터마이징**: 기본 라이트 모드 설정, 수동 라이트/다크 모드 전환 스위치, 기상 상태 맞춤 12종 동적 배경 그라데이션, `localStorage` 기반 최근 본 도시 뱃지

## 📡 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**: 복잡한 회원가입이나 Secret Key 발급 절차 없이 HTTPS 엔드포인트 호출만으로 전 세계 실시간 기상(`forecast`), 대기질(`air-quality`), 지오코딩(`geocoding`) 데이터를 무료로 제공하는 완전 공개형(Public) REST API입니다.
- **UI 컴포넌트와 API 통신 로직 분리 (`src/api/weather.js`)**: UI 표현 계층(`App.jsx`, `components/`)과 데이터 통신 계층(`weather.js`)을 철저히 분리(Decoupling)하여 데이터 패칭 로직 변경 시 UI에 영향을 주지 않도록 설계했으며, 재사용성과 테스트 용이성을 극대화했습니다.
- **도시 검색 디바운스(Debounce)의 필요성**: 검색창에 도시명을 한 글자씩 입력할 때마다 즉시 API를 호출하면 순간적으로 수십 건의 불필요한 네트워크 트래픽이 발생합니다. 이는 서버에 비의도적 DoS 부하를 줄 뿐 아니라 API 서버로부터 `429 Too Many Requests`로 IP가 차단될 위험이 있으므로, 사용자의 타이핑이 멈춘 후 400ms 뒤에 1회만 호출하도록 디바운스를 적용했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

- **Public API vs Private/Secret API (키 은닉과 백엔드의 필요성)**:
  - Open-Meteo와 같은 완전 공개 API는 브라우저(React 클라이언트)에서 직접 호출해도 무방합니다.
  - 하지만 결제 모듈, SMS 발송, 사내 DB 연동 등 **비밀 키(Secret Key)**가 필요한 유료/보안 API의 경우, 클라이언트 소스코드에 키를 포함시키면 브라우저의 Network 탭이나 빌드된 JS 파일을 통해 **100% 키가 탈취**되어 막대한 금전 피해나 데이터 유출 사고로 이어집니다.
  - 따라서 이런 보안 API는 반드시 **백엔드 프록시 서버(BFF, Backend For Frontend)**를 중간에 두어 클라이언트는 자체 인증 세션으로 백엔드와 통신하고, 백엔드 서버 환경변수(`ENV`)에 Secret Key를 은닉하여 API를 대리 호출해야 합니다.
- **HTTPS 혼합 콘텐츠(Mixed Content) 방어**:
  - 배포 사이트가 안전한 `https://` 프로토콜을 사용할 때, 내부 자바스크립트에서 암호화되지 않은 `http://` API 엔드포인트를 호출하면 브라우저 보안 엔진에 의해 Mixed Content로 통신이 강제 차단됩니다.
  - 이는 평문 통신 도중 패킷 스니핑이나 중간자 공격(MITM)에 의해 데이터가 변조되는 것을 방지하기 위한 필수적인 웹 보안 규칙입니다.

## 🎨 커스터마이징한 부분

1. **기본 라이트 모드 & 수동 라이트/다크 모드 토글 (`ThemeToggle.jsx`)**:
   - 주간에 편안하게 볼 수 있는 밝은 라이트 모드를 기본값으로 설정
   - 헤더에 `Sun`/`Moon` 아이콘이 부드럽게 회전하는 테마 전환 토글 버튼 추가
   - `localStorage`(`weather_theme_mode_v1`)에 테마 상태를 저장하여 새로고침 후에도 사용자 설정 영속화
2. **기상 상태 맞춤 12종 동적 배경 그라데이션**:
   - WMO 기상 코드(맑음, 구름, 비, 눈, 뇌우, 안개)와 테마 모드(라이트/다크)를 결합하여 현재 도시의 날씨에 맞는 12가지 감성 배경 그라데이션 자동 적용
   - `transition: background 0.8s ease`를 통한 부드러운 배경색 전환 연출
3. **글래스모피즘(Glassmorphism) 카드 디자인**:
   - 배경 그라데이션 위에서도 모든 기상 수치와 차트가 선명하게 읽히도록 카드에 `backdrop-filter: blur(14px)` 및 반투명 배경색 적용
4. **최근 본 도시 자동 저장 및 원클릭 뱃지 (`RecentCities.jsx`)**:
   - 사용자가 검색하거나 선택한 도시를 `localStorage`에 최대 5개까지 누적 저장하여 상단 뱃지로 원클릭 재조회 지원
